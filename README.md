# خلاصه‌گر ویدیوهای یوتیوب

وب‌اپ فارسی راست‌چین برای گرفتن لینک یوتیوب، استخراج زیرنویس و ساخت خلاصه حرفه‌ای با مدل زبانی.

## پیش‌نیازها
- Python 3.10 یا جدیدتر
- کلید API از OpenAI
- دسترسی اینترنت برای دریافت زیرنویس

## اجرا در ویندوز
1. فایل ZIP را استخراج کن.
2. داخل پوشه پروژه ترمینال را باز کن.
3. محیط مجازی بساز و فعال کن:
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```
4. وابستگی‌ها را نصب کن:
   ```powershell
   pip install -r requirements.txt
   ```
5. فایل `.env.example` را به `.env` تغییر نام بده و کلید API را در آن قرار بده.
6. اجرا:
   ```powershell
   uvicorn app:app --reload
   ```
7. در مرورگر باز کن: http://127.0.0.1:8000

## اجرا در Linux / macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# کلید API را در .env قرار بده
uvicorn app:app --reload
```

## امکانات
- لینک‌های youtube.com و youtu.be
- تلاش برای دریافت زیرنویس فارسی؛ در صورت نبودن، ترجمه زیرنویس قابل‌ترجمه به فارسی
- سه سطح خلاصه: کوتاه، استاندارد و مفصل
- کپی خلاصه و ذخیره به‌صورت فایل متنی

## محدودیت‌ها و نکات
- این نسخه به زیرنویس ویدیو متکی است و مستقیماً صدای ویدیو را پیاده‌سازی گفتار نمی‌کند.
- ویدیوهای خصوصی، محدودشده، زنده یا فاقد زیرنویس قابل‌دسترسی ممکن است کار نکنند.
- برای انتشار عمومی، کلید API را فقط روی سرور نگه دار؛ هرگز آن را در کد فرانت‌اند قرار نده.
- هزینه استفاده از API بر اساس میزان متن و مدل انتخابی محاسبه می‌شود.
- رعایت شرایط استفاده یوتیوب و حقوق ناشر محتوا بر عهده بهره‌بردار است.
